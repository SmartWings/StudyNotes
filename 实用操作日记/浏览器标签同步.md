# Floccus 详细使用教程

## 一、Floccus 简介
Floccus 是一个开源的书签同步工具，通过 WebDAV 或 Nextcloud/ownCloud 实现跨浏览器同步。

### 支持的浏览器
✅ Chrome/Chromium  
✅ Firefox  
✅ Edge  
✅ Vivaldi  
✅ Opera  

### 支持的同步后端
1. **Nextcloud/ownCloud Bookmarks**（推荐）
2. **WebDAV**（支持坚果云、Dropbox等）
3. **Gitea**（本地git服务等）
4. **本地文件**（高级用户）

## 二、准备工作

### 1. 选择存储服务
| 服务 | 免费空间 | 优点 | 缺点 |
|------|---------|------|------|
| **坚果云** | 1GB/月上传 | 国内速度快，WebDAV稳定 | 免费空间较小 |
| **Nextcloud** | 自定 | 完全控制，功能丰富 | 需要自建服务器 |
| **ownCloud** | 自定 | 开源 | 配置较复杂 |
| **Koofr** | 10GB | 欧洲服务，支持WebDAV | 国内速度可能慢 |

### 2. 安装 Floccus
**Chrome/Edge：**
1. 打开 Chrome 网上应用店
2. 搜索 "Floccus"
3. 点击 "添加到 Chrome"

**Firefox：**
1. 打开 Firefox 附加组件商店
2. 搜索 "Floccus"
3. 点击 "添加到 Firefox"

## 三、配置教程（以坚果云为例）

### 步骤 1：获取坚果云 WebDAV 信息
1. **注册坚果云账号**（如已有则跳过）
2. 登录坚果云网页版
3. 点击右上角用户名 → "账户信息"
4. 选择 "安全选项" 标签页
5. 找到 **第三方应用管理**
6. 点击 "添加应用密码"
   - 应用名称：Floccus
   - 权限：勾选 "同步" 和 "文件读写"
7. 记录生成的 **应用密码**
8. 记下你的 **服务器地址**：
   ```
   https://dav.jianguoyun.com/dav/
   ```

### 步骤 2：配置 Floccus 扩展

1. **打开 Floccus 设置**
   - 点击浏览器工具栏中的 Floccus 图标
   - 或右键图标 → "选项"

2. **添加新账户**
   ```
   账户类型：WebDAV
   账户名：自定义（如"坚果云书签"）
   ```

3. **填写 WebDAV 信息**
   ```yaml
   URL: https://dav.jianguoyun.com/dav/
   路径: /floccus/bookmarks.xbel  # 可以自定义
   用户名: 你的坚果云邮箱
   密码: 刚才生成的应用密码
   ```

4. **高级设置**
   ```yaml
   同步频率: 15分钟  # 建议值
   冲突解决: 合并更改  # 首次同步选"远程覆盖本地"
   书签位置: 选择要同步的文件夹
   ```

### 步骤 3：首次同步

1. **备份现有书签**
   - 在浏览器中导出书签（HTML格式）
   - 保存在安全位置

2. **执行同步**
   ```操作步骤：
   1. 在Floccus设置页面，点击账户右侧的"同步"
   2. 选择同步方向：
      - 首次使用：推荐"用远程覆盖本地"
      - 已有书签：先备份，再选择"合并"
   3. 等待同步完成
   ```

3. **验证同步结果**
   - 检查坚果云网页版，查看是否生成书签文件
   - 在另一台设备上配置Floccus，测试同步效果

## 四、多浏览器配置

### 配置顺序建议：
```mermaid
graph LR
    A[主力浏览器] --> B[配置Floccus]
    B --> C[首次同步]
    C --> D[其他浏览器安装Floccus]
    D --> E[用远程覆盖本地]
    E --> F[所有浏览器同步完成]
```

### 具体步骤：
1. **在主浏览器完成配置和首次同步**
2. **在其他浏览器安装 Floccus**
3. **使用相同配置信息**
   - 相同的 WebDAV URL
   - 相同的路径
   - 相同的账号密码
4. **首次同步选择"用远程覆盖本地"**
5. **验证各浏览器书签一致**

## 五、高级配置

### 1. 同步特定文件夹
```配置方法：
1. 在Floccus设置中点击"高级"
2. 找到"书签位置"
3. 选择要同步的特定文件夹
4. 可以设置多个同步规则
```

### 2. 排除特定文件夹
- 目前Floccus不支持排除功能
- 解决方案：将要排除的书签放在不同步的文件夹中

### 3. 自动同步设置
```json
{
  "同步间隔": "15分钟",  // 可选：5,15,30,60分钟
  "空闲时同步": "开启",
  "启动时同步": "开启"
}
```

### 4. 冲突处理策略
| 选项 | 适用场景 |
|------|---------|
| **本地优先** | 信任当前设备的更改 |
| **远程优先** | 信任云端的最新更改 |
| **合并** | 谨慎使用，可能重复 |
| **新建副本** | 创建冲突副本供手动处理 |

## 六、故障排除

### 常见问题及解决方案

#### 1. **同步失败：认证错误**
```检查项：
✅ 确认用户名（邮箱）正确
✅ 确认使用的是应用密码，不是登录密码
✅ 确认WebDAV URL正确
✅ 检查坚果云账户是否正常
```

#### 2. **同步失败：网络错误**
```
解决方法：
1. 检查网络连接
2. 尝试切换网络（如手机热点）
3. 暂时关闭防火墙/安全软件
4. 如果是国内网络，确保不是DNS问题
```

#### 3. **书签重复**
```
处理步骤：
1. 停止所有设备的同步
2. 在一个浏览器中整理书签
3. 删除重复项
4. 手动触发同步
5. 其他设备选择"远程覆盖本地"
```

#### 4. **同步缓慢**
```
优化建议：
1. 减少同步的书签数量
2. 增加同步间隔时间
3. 分批同步不同文件夹
4. 检查网络状况
```

### 调试信息获取
1. 打开 Floccus 设置
2. 滚动到底部，点击 "调试信息"
3. 复制日志信息用于排查问题

## 七、备份策略

### 双重备份方案
```
方案一：自动备份
1. Floccus 同步到坚果云
2. 坚果云同步到本地文件夹

方案二：手动备份
1. 每月导出一次书签HTML
2. 使用Git管理书签版本
```

### 导出书签
```步骤：
Chrome: 书签管理器 → 右上角三点 → 导出书签
Firefox: 书签 → 管理书签 → 导入和备份 → 导出
Edge: 收藏夹 → 设置 → 导出收藏夹
```

## 八、最佳实践

### 日常使用建议
1. **整理习惯**
   - 每周花5分钟整理书签
   - 删除失效链接
   - 使用文件夹分类

2. **同步策略**
   ```
   工作日：自动同步（每15分钟）
   周末：手动触发一次完整同步
   每月：检查同步日志
   ```

3. **标签系统**
   - 使用统一命名规范
   - 建议结构：类别/子类别/名称
   - 示例：Work/Design/UI_Resources

### 多设备管理
```设备类型配置建议：
1. 主力电脑：完整同步所有书签
2. 笔记本电脑：同步常用文件夹
3. 手机：通过坚果云APP访问（Floccus无手机版）
```

## 九、移动端访问方案

由于 Floccus 没有移动端APP，可以通过以下方式访问：

### 方案1：坚果云APP
1. 在坚果云APP中找到书签文件
2. 使用支持XBEL格式的APP打开
3. 或通过网页版坚果云访问

### 方案2：定期导出
1. 每月导出一次HTML文件
2. 发送到手机
3. 在手机浏览器中导入

### 方案3：配合其他工具
1. 使用 Raindrop.io 作为补充
2. 重要书签在两个平台都保存

## 十、完整工作流程示例

### 新设备设置流程
```bash
1. 安装浏览器
2. 安装Floccus扩展
3. 配置WebDAV连接（坚果云）
4. 首次同步（远程覆盖本地）
5. 验证书签完整性
6. 设置自动同步
7. 添加到日常检查清单
```

### 迁移到新电脑
```bash
1. 旧电脑确保完成最后一次同步
2. 在新电脑安装浏览器和Floccus
3. 配置相同的同步账户
4. 执行同步
5. 对比两台电脑的书签
6. 确认无误后使用新电脑
```

---

## 注意事项
1. ⚠️ **不要在多设备同时编辑书签**，避免冲突
2. ⚠️ **定期检查同步状态**，特别是重要书签
3. ⚠️ **保留本地备份**，防止云端数据丢失
4. ⚠️ **更新扩展时**，检查配置是否保留
