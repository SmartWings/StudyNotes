将SRT字幕文件与MKV视频文件合并有多种方法，这里为您介绍几种常用且简单的方法：

## 一、使用播放器直接加载（不改变原文件）
**最简单快速**，适合观看使用。

### 1. VLC播放器
- 将视频和字幕文件放在同一文件夹，且文件名相同（如：`video.mkv` 和 `video.srt`）
- 用VLC打开视频文件，会自动加载字幕
- 如果没自动加载：右键视频 → 字幕 → 选择字幕轨道

### 2. PotPlayer（推荐）
- 直接将字幕文件拖拽到正在播放的视频窗口上
- 或按快捷键 `F` 添加字幕文件

## 二、永久合并到视频文件（硬字幕）
字幕会永久嵌入视频画面中。

### 1. 使用 **FFmpeg**（免费、强大）
```bash
ffmpeg -i input.mkv -vf "subtitles=input.srt" output.mkv
```

**常用选项：**
- 指定字幕样式：
```bash
ffmpeg -i input.mkv -vf "subtitles=input.srt:force_style='Fontsize=24,PrimaryColour=&HFFFFFF&'" output.mkv
```

### 2. 使用 **MKVToolNix**（推荐）
**最佳选择**，保持视频质量，可灵活开关字幕。

1. 下载安装 MKVToolNix
2. 打开 `MKVToolNix GUI`
3. 将MKV视频文件拖入
4. 将SRT字幕文件拖入
5. 右侧可设置字幕语言、名称等
6. 点击“开始混流”生成新文件

## 三、封装字幕（软字幕）
字幕作为独立轨道存在，可开关。

### 使用 MKVToolNix（同上）
这是最推荐的方法，因为：
- 不重新编码，速度快
- 保持原视频质量
- 字幕可随时开关
- 支持多字幕轨道

## 四、简单软件推荐

### 1. **Format Factory（格式工厂）**
- 视频 → 选择MKV
- 添加文件 → 输出配置 → 附加字幕
- 开始转换

### 2. **HandBrake**
- 导入视频文件
- 字幕选项卡 → 导入SRT
- 开始编码

## 📌 推荐方案
1. **仅观看**：使用PotPlayer或VLC直接加载
2. **永久保存**：使用MKVToolNix封装（最推荐）
3. **需要硬字幕**：使用FFmpeg或格式工厂

**注意**：如果遇到字幕乱码，先用记事本将SRT文件另存为UTF-8编码格式。



使用 FFmpeg 将 MKV 转换为 MP4 有多种方法，具体取决于您的需求：

## 一、基本转换（直接复制流）

### 1. **简单转换**（推荐大多数情况）
```bash
ffmpeg -i input.mkv -c copy output.mp4
```
- `-c copy`：直接复制音视频流，不重新编码
- **优点**：极快，无损质量
- **缺点**：如果MKV中的编码格式MP4不支持，可能会失败

### 2. **自动检测并转换不兼容的编码**
```bash
ffmpeg -i input.mkv -c:v copy -c:a aac -b:a 192k output.mp4
```
- `-c:v copy`：视频流直接复制
- `-c:a aac`：音频转为AAC格式（MP4标准）
- `-b:a 192k`：音频比特率192kbps

## 二、重新编码转换

### 1. **高质量H.264转换**
```bash
ffmpeg -i input.mkv -c:v libx264 -crf 23 -preset medium -c:a aac -b:a 192k output.mp4
```
**参数说明：**
- `-c:v libx264`：使用H.264编码器
- `-crf 23`：质量级别（18-28，越小质量越好）
- `-preset medium`：编码速度与压缩率的平衡
  - `ultrafast` `superfast` `veryfast` `faster` `fast` `medium` `slow` `slower` `veryslow`
- `-c:a aac -b:a 192k`：音频设置

### 2. **保持原始质量**
```bash
ffmpeg -i input.mkv -c:v libx264 -crf 18 -preset slow -c:a aac -b:a 320k output.mp4
```

## 三、常用场景

### 1. **批量转换**
```bash
for f in *.mkv; do ffmpeg -i "$f" -c copy "${f%.mkv}.mp4"; done
```
或Windows批处理：
```batch
for %%i in (*.mkv) do ffmpeg -i "%%i" -c copy "%%~ni.mp4"
```

### 2. **提取并转换特定流**
```bash
# 只选择第一个视频和音频流
ffmpeg -i input.mkv -map 0:v:0 -map 0:a:0 -c copy output.mp4

# 选择特定语言的音频（如英语）
ffmpeg -i input.mkv -map 0:v:0 -map 0:a:m:language:eng -c copy output.mp4
```

### 3. **带字幕转换**
```bash
# 嵌入硬字幕
ffmpeg -i input.mkv -vf "subtitles=input.mkv" -c:v libx264 -c:a aac output.mp4

# 添加软字幕（需要MP4支持）
ffmpeg -i input.mkv -i subtitle.srt -c copy -c:s mov_text output.mp4
```

## 四、常见问题解决

### 1. **音频编码问题**
如果遇到音频编码错误：
```bash
# 转换音频为AAC
ffmpeg -i input.mkv -c:v copy -c:a aac -strict experimental output.mp4
```

### 2. **时间戳问题**
```bash
ffmpeg -i input.mkv -c copy -avoid_negative_ts make_zero output.mp4
```

### 3. **保留元数据**
```bash
ffmpeg -i input.mkv -c copy -map_metadata 0 output.mp4
```

## 五、推荐方案

### **最常用命令**
```bash
# 尝试直接复制（最快）
ffmpeg -i input.mkv -c copy output.mp4

# 如果失败，使用这个（兼容性好）
ffmpeg -i input.mkv -c:v libx264 -crf 23 -preset medium -c:a aac -b:a 192k output.mp4
```

### **高质量转换**
```bash
ffmpeg -i input.mkv \
  -c:v libx264 -crf 18 -preset slow \
  -c:a aac -b:a 320k \
  -movflags +faststart \
  output.mp4
```
- `-movflags +faststart`：使MP4适合在线流媒体播放

## 六、GUI工具推荐（如果不想用命令行）

1. **HandBrake**：免费开源，界面友好
2. **Format Factory（格式工厂）**：中文界面，功能全面
3. **XMedia Recode**：功能强大，支持批量

## 注意事项
1. **检查编码器**：运行 `ffmpeg -codecs` 查看支持的编码格式
2. **测试片段**：先转换一小段测试：`-t 30`（30秒）
3. **保留原始**：转换前备份原始MKV文件
